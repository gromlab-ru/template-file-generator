# Возможности Template File Generator

Пакет `@gromlab/template-file-generator` предоставляет CLI `template-file-generator`, программный API и два скилла: английский `template-generation` и русский `template-generation-ru`.

## Генерация

- Источник — `.templates/` в рабочем каталоге CLI; непосредственная подпапка задаёт имя шаблона.
- Обязательный позиционный аргумент `<имя>` задаёт `name`.
- Необязательный `[путь]` задаёт папку вывода относительно рабочего каталога; допустим абсолютный путь.
- Переменные `--ключ значение` или `--ключ=значение` подставляются в пути и содержимое UTF-8 файлов.
- Модификаторы: `pascalCase`, `camelCase`, `kebabCase`, `snakeCase`, `screamingSnakeCase`, `upperCase`, `lowerCase`, `upperCaseAll`, `lowerCaseAll`.
- При отсутствии обязательных переменных или шаблона CLI возвращает ошибку до генерации.

Пустые папки, символические ссылки, бинарные файлы, условия и циклы не поддерживаются. Шаблоны являются локальными соглашениями проекта и не устанавливаются автоматически вместе с пакетом.

## Конфликты и вывод

- Проверка существующих верхних папок из шаблона и конфликтов файлов.
- `--overwrite` разрешает замену файлов из плана; остальные файлы не удаляются.
- Вывод путей, дерева созданных файлов и переменных.
- Ненулевой код завершения при ошибке. Запись последовательная, без автоматического отката.

## Автодополнение

```bash
template-file-generator completion --shell bash
template-file-generator install-autocomplete --shell bash
```

Также поддерживаются zsh и fish. Команды предназначены для глобальной установки. Подсказки ищут ближайшую `.templates/` вверх по дереву каталогов и используют служебные команды `__list-templates` и `__list-vars <шаблон>`.

Генерация CLI, в отличие от подсказок, использует только `.templates/` текущего рабочего каталога.

## Обновление

CLI определяет запуск через `npx`, локальный бин, прямой запуск и глобальную установку. Проверка обновлений пропускается при `npx`, отсутствии TTY или `--skip-update`. В интерактивном режиме возможен запрос на глобальное обновление. После отказа повторный запрос откладывается на 24 часа.
